Setup

1

Install

Mac: open the download and drag ScapeMar to Applications. Windows: run the setup file. Linux: extract the zip.

2

Open ScapeMar

On Mac, approve the network prompt. If macOS blocks the app, open System Settings → Privacy & Security and click Open Anyway. If Windows shows a blue warning, click More info, then Run anyway.

3

Play

ScapeMar checks for updates and opens the game on its own. Click New User to make an account, or sign in to world 255.

Quest Helper and 117 HD are selected for RuneLite's Plugin Hub. If either is missing, install it from the Plugin Hub in RuneLite. No-install Windows zip, release details and checksums are on the release page.
