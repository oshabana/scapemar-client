What this is

Faithful first. Fancy never.

We are not making a new game with the RuneScape name on it. The goal is a server where the numbers, the animations and the odd little details match the real thing, so what you learn here carries over.

⚔

Built to match the real game

Hit chances, damage, drop rates and timings are taken from the OSRS Wiki and checked against footage of the real game. If a value can't be sourced, it isn't counted as done.

✦

The normal client, not a clone

You play in RuneLite, the client most players already use. Plugins like Quest Helper and 117 HD come along, so it looks and feels familiar from the first minute.

↻

Nothing to set up

Java is included. Open ScapeMar and it checks for updates, installs them and starts the game. There are no menus to pick and no settings to get wrong.

Get started

Download ScapeMar

Pick your computer. Java and the server connection are included, so there is nothing else to install.

⌘MacScapeMar-macos.dmgDownload ▦WindowsScapeMar-windows-setup.exeDownload >_LinuxScapeMar-linux.zipDownload

Install

Mac: open the download and drag ScapeMar to Applications. Windows: run the setup file. Linux: extract the zip.

Open ScapeMar

It checks for updates and starts the game by itself. The first launch can take a minute while it downloads the game files.

Play

On the login screen click New User to make an account, or sign in. You join World 255.

The downloads are not signed with a paid developer certificate, so the first launch shows a warning. Mac: if macOS blocks the app, open System Settings → Privacy & Security and click Open Anyway; you will also be asked for your password once to allow the local connection. Windows: click More info, then Run anyway. A no-install Windows zip and file checksums are on the release page.

Questions

Good to know

Is this the real RuneScape?

No. It is an independent fan project and is not affiliated with Jagex, RuneLite or RSProx. It is a separate server that tries to play like Old School RuneScape.

Is it finished?

No. It is a work in progress. Most of the core game works, but some bosses, minigames, quests and all raids are still to come, and some details will be off.

Does it cost anything?

No. The client is free.

How do updates work?

Each time you open ScapeMar it checks for a newer version, installs it, and then starts the game. If you are offline it starts with what you already have.

What is installed on my computer?

The ScapeMar launcher, its own copy of Java, the official RSProx launcher, and a small login plugin for RuneLite. It contains no server code and no modified RuneLite. The source is public on GitHub.

Quest Helper or 117 HD is missing. What do I do?

Open RuneLite's wrench icon, open the Plugin Hub, search for the plugin and click Install.

ScapeMar is unofficial and is not affiliated with Jagex, RuneLite, or RSProx.
