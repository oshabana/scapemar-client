SCAPEMAR

Java is included. Double-click Launch ScapeMar. It checks for updates and
opens the game. On the login screen, click New User to pick a username and
password, or Existing User to sign in.

If Quest Helper or 117 HD does not appear, use RuneLite's wrench icon, open
Plugin Hub, and install it there.

This bundle is independent of Jagex, RuneLite, RSProx, Quest Helper, and 117 HD.
The ScapeMar connection settings point at 82.25.84.115:43594.
